# Figma 设计任务书：AI 原生企业知识工作台（智能问答 + 知识图谱）

## 〇、设计总则（先读）

1. **全新产品**：请勿参考 / 模仿 WeKnora、TDesign、Notion、飞书知识库、语雀、印象笔记等现有产品的视觉风格、布局或组件形态。
2. **本任务书规定"页面有哪些功能模块、点击跳转到哪里"（硬性要求）；不规定视觉风格（颜色 / 像素 / 字体 / 排版方式均自由）**。每个模块的呈现形态由你设计，但模块与交互必须完整覆盖。
3. 建议先给出 **2~3 个差异化方向提案**（如：图谱优先探索式工作台 / 对话优先 AI 工作台 / 文档管理升级智能空间），说明取舍并推荐其一，再按推荐方向完成全量页面。
4. 产品定位：桌面浏览器优先、企业级、信息密度高、仅中文、单工作区多知识库、组织共享。

## 一、认证与初始化

### 1. 登录页
**用途**：用户入口。
**模块清单**：
- 品牌区（Logo + 产品名 + 一句产品定位语）
- 登录表单：账号输入框、密码输入框、登录按钮、错误提示区
- 忘记密码说明（"请联系管理员重置"文案即可）
**交互与跳转**：
- 登录成功 → 跳转知识库列表页（若系统未初始化，跳转初始化页）
- 若系统未初始化 → 显示"前往初始化"入口 → 初始化页

### 2. 首次初始化页
**用途**：部署后首次使用，创建管理员账号。
**模块清单**：
- 欢迎语 + 步骤说明
- 表单：管理员昵称、账号、密码、确认密码、初始化按钮
**交互与跳转**：
- 初始化成功 → 自动登录 → 知识库列表页

### 3. 注册页（邀请链接进入）
**用途**：管理员邀请成员，成员通过链接注册。
**模块清单**：
- 邀请来源提示（"你已被邀请加入 XX 工作区"）
- 表单：昵称、账号、密码、确认密码、注册按钮
**交互与跳转**：
- 注册成功 → 自动登录 → 知识库列表页

## 二、主框架（全局壳）

**用途**：所有登录后页面的容器。
**模块清单**：
- 导航区：品牌 Logo；主导航（知识库 / 会话 / 组织）；会话历史列表入口（见会话页）；底部用户区（头像、昵称、设置入口、退出登录）
- 内容区：渲染当前页面
- 全局组件挂载点：全局拖拽上传遮罩（拖文件进窗口出现，显示上传进度）、统一消息提示、统一确认对话框
**交互与跳转**：
- 导航"知识库" → 知识库列表页；"会话" → 会话页（或新建会话页）；"组织" → 组织列表页
- 用户区"设置" → 打开设置中心；"退出登录" → 返回登录页
- 全局拖拽：把文件拖入窗口 → 若当前在知识库详情/会话页则上传到对应上下文，否则提示先进入知识库

## 三、知识库

### 4. 知识库列表页
**用途**：查看与管理所有知识库。
**模块清单**：
- 页头：页面标题"知识库"、副标题、新建知识库按钮
- 视图切换区：全部 / 我的 / 收藏 / 最近（各项带数量）
- 组织分组区：共享给我的知识库按来源组织分组（组织名 + 数量）
- 知识库卡片：名称、描述（无则占位文案）、徽章（文档数量、"知识图谱"徽章）、来源标识（我创建的 / 来自 XX 组织）、收藏星标、更多操作菜单
- 置顶分组标题（置顶库置顶展示）
- 未初始化 / 处理中知识库：弱化 + 提示
- 状态：加载骨架屏 / 空状态（引导文案 + 新建按钮）
**交互与跳转**：
- 点击卡片 → 知识库详情页
- 新建知识库 → 打开新建向导（见 §5）
- 星标 → 切换收藏；更多菜单 → 置顶/取消置顶、复制、设置、删除
- 删除 → 确认对话框 → 删除后刷新列表
- 复制 → 进度提示，完成后出现在列表
- 设置 → 打开知识库设置弹窗（见 §8）
- 切换视图（全部/我的/收藏/最近）与组织分组 → 过滤下方卡片

### 5. 新建 / 编辑知识库向导
**用途**：创建知识库的完整配置流程（编辑时复用，已填项回显）。
**模块清单**（分节或向导步骤，均含"上一步/下一步/保存"）：
- 基本信息：名称、描述（类型固定文档库，不提供选择）
- 索引策略：向量搜索（默认开）、知识图谱抽取（开关）；至少启用其一，否则不可继续
- 模型：Embedding 模型下拉、摘要模型下拉（数据来自设置中心已配置模型；未配置时提示跳转设置）
- 分块配置：分块策略选择、块大小、重叠度
- 解析引擎规则：文件类型（PDF / Word / 图片 / Markdown）→ 解析引擎（Docling / MinerU）映射，提供默认值
**交互与跳转**：
- 创建成功 → 跳转该知识库详情页
- 编辑模式入口：知识库列表卡片"设置"、详情页"设置"按钮
- 提示跳转设置中心（模型未配置时）

### 6. 知识库详情页（文档管理 Tab）
**用途**：管理该知识库的文档。
**模块清单**：
- 面包屑区：知识库 > 当前库名 > Tab（文档 / 知识图谱）
- 信息按钮（弹层：文档数、分块数、存储用量等统计）、设置按钮
- 文件夹树区（可折叠）：根目录 + 各级文件夹；新建文件夹、重命名文件夹
- 路径面包屑（当前所在文件夹）
- 工具栏：
  - 关键词搜索框
  - 标签筛选（弹出面板：标签多选带计数、搜索标签、管理标签入口）
  - 文件类型筛选（PDF / Word / 图片 / Markdown）
  - 解析状态筛选（全部 / 处理中 / 成功 / 失败）
  - 来源筛选（上传 / URL 导入 / 手动创建）
  - 更新时间范围
  - 视图切换（网格 / 列表）
  - 上传入口（下拉：上传文件 / 从 URL 导入 / 手动创建）
- 文档列表项：文件名、所在文件夹、类型图标、标签、大小、解析状态（处理中进度 / 失败原因可重试）、更新时间；行操作：预览、重新解析、取消解析、下载、移动到文件夹、编辑标签、删除
- 多选：勾选（列表）/ 框选（网格）；选中后出现批量操作栏：批量删除、批量重新解析、批量打标签、移动到文件夹
- 上传进度面板（上传中显示进度、失败提示）
- 空状态（引导上传第一个文档）、筛选无结果提示
**交互与跳转**：
- 点击文档 → 打开文档详情视图（见 §7）
- 上传文件 / URL / 手动 → 触发解析任务，进度面板可见
- 手动创建 → 打开手动创建弹窗（Markdown 编辑器 + 元数据表单）
- 文件夹树选中 → 列表切换为该文件夹内容；文档可拖拽到文件夹树实现移动
- 标签管理入口 → 打开标签管理抽屉（增删改标签、查看每个标签下的文档数）
- 切换 Tab"知识图谱" → 知识图谱页（见 §8）
- 设置按钮 → 知识库设置弹窗（见 §9）

### 7. 文档详情视图（预览 / 抽屉或独立视图均可）
**用途**：查看单篇文档的完整信息。
**模块清单**：
- 头部：文档标题、下载按钮、解析时间线入口
- 元数据区：类型、来源、上传 / 更新时间、标签（可编辑）
- 正文预览：Markdown 渲染 / 图片预览
- 自动摘要区：摘要内容 + 重新生成按钮
- 解析时间线面板：上传 → 解析 → 向量化 → 图谱抽取各阶段状态、耗时、可展开详情
- 分块管理区：文本分块列表（含分块内图片信息）；每块可编辑；每块有版本历史（快照列表、行级 diff、一键回滚）
**交互与跳转**：
- 编辑标签 → 打开标签编辑弹窗 → 保存后回显
- 重新生成摘要 → 进度提示 → 更新摘要
- 编辑分块 → 保存后提示"将重新向量化"
- 版本历史 → 展开 diff 视图 → 回滚需确认

### 8. 知识图谱页（知识库详情 Tab）
**用途**：可视化查看该知识库的实体关系网络。
**模块清单**：
- 画布区：节点 = 实体（不同实体类型不同样式）、边 = 关系（标注关系名）；支持缩放、平移、拖拽节点
- 顶部工具：实体搜索框、实体类型筛选、图例
- 节点详情面板：实体名称、类型、描述、关联文档列表
- 空状态：提示"启用知识图谱抽取后，新上传文档将自动构建图谱"
**交互与跳转**：
- 点击节点 → 打开/更新节点详情面板
- 详情面板中点击关联文档 → 跳转该文档详情视图（§7）

### 9. 知识库设置（弹窗，侧边导航分节）
**用途**：编辑知识库配置与共享。
**模块清单**：
- 基本信息：名称、描述、类型（只读）
- 索引策略：向量搜索 / 知识图谱抽取
- 分块配置
- 解析引擎规则
- 模型：Embedding / 摘要模型
- 检索：召回阈值、TopK
- 共享：选择组织 + 权限（可查看 / 可编辑）
- 危险操作区：删除知识库（二次确认）
**交互与跳转**：
- 保存 → 提示成功；删除 → 确认 → 返回知识库列表

## 四、会话（智能问答）

### 10. 会话列表（主框架导航区内）
**用途**：查看与管理历史会话。
**模块清单**：
- 会话搜索框
- 日期分组：今天 / 昨天 / 更早
- 会话项：标题（自动生成）、时间、置顶标识；操作：置顶 / 取消置顶、重命名、删除
- 批量管理模式：多选 + 批量删除、一键清空全部
**交互与跳转**：
- 点击会话项 → 打开该会话聊天页
- 新建会话入口（导航区"会话"或"+ 新对话"）→ 打开空会话聊天页

### 11. 聊天页（会话）
**用途**：与智能体对话，获取基于知识库的答案。
**模块清单**：
- 消息区（空会话时无消息）：
  - 用户消息：文本、@提及的知识库 / 文件 chip、图片、附件
  - 助手消息：
    - 流式 Markdown 内容
    - 深度思考：可折叠的推理过程
    - RAG 管线进度：检索 → 重排 → 合并 → 生成的阶段指示
    - 工具调用过程树：思考 / 调用工具 / 工具结果，逐条可折叠，可查看工具引用的来源
    - 引用来源：答案中可点击的引文（悬浮显示来源摘要）+ 侧边引用抽屉（列出全部引用文档与分块）
    - 答案工具条：复制、加入知识库、请求详情（模型 / token 用量）
- 输入区（空会话时居中大输入框）：
  - 多行输入框（自动增高）
  - 控件：@提及（选择知识库 / 文件）、图片上传、附件上传、模型选择器、Web 搜索开关、发送按钮 / 停止生成按钮
- 辅助：向上滚动加载历史、滚动到底部按钮
**交互与跳转**：
- 发送 → 流式输出助手回答（阶段进度、工具调用逐步呈现）
- @提及 → 打开选择器弹层（知识库列表 / 文件列表，可搜索）→ 选中后以 chip 显示在输入框
- 图片 / 附件 → 上传后预览缩略图，可移除
- 模型选择器 → 下拉切换当前会话模型
- Web 搜索开关 → 开关联网搜索
- 点击引文 → 悬浮显示来源摘要；引用抽屉按钮 → 侧边抽屉展示全部引用
- 答案工具条"加入知识库" → 选择目标知识库弹窗 → 保存为文档
- 停止生成 → 中断当前回答
- 会话标题自动生成并回写会话列表

## 五、组织（共享）

### 12. 组织列表页
**用途**：管理组织（空间）与成员。
**模块清单**：
- 页头：标题"组织"、副标题、创建组织按钮
- 组织卡片：名称、成员数、共享给该组织的知识库数
- 待处理邀请通知（未处理时亮起，含数量）
- 状态：骨架屏 / 空状态
**交互与跳转**：
- 点击组织卡片 → 打开组织设置弹窗（§13）
- 创建组织 → 打开创建弹窗（名称、描述）
- 邀请通知 → 弹出邀请列表 → 接受 / 拒绝

### 13. 组织设置弹窗
**模块清单**：
- 基本信息：名称、描述
- 成员管理：成员列表（头像、昵称、角色）、添加成员、移除成员、生成邀请链接、角色调整（Owner / Admin）
- 共享概览：共享给该组织的知识库列表（只读）
**交互与跳转**：
- 生成邀请链接 → 复制链接（成员通过链接注册后自动入组织）
- 加入组织：通过邀请链接进入组织列表页并提示加入

## 六、设置中心

**用途**：账号、工作区、模型、系统管理。侧边分组导航 + 内容区，分组如下（功能点硬性要求，布局自选）：

- **账号组**
  - 个人资料：昵称、邮箱、头像、修改密码（旧密码 + 新密码 + 确认）
- **工作区组**
  - 工作区信息：名称、创建时间、存储用量概览（只读）
  - 成员管理：成员列表、角色（Owner / Admin）、邀请成员、移除成员、转移所有权（仅 Owner）
- **模型与运行时组**
  - 模型管理：模型列表（名称、供应商、模型 ID、类型：对话 / Embedding / 摘要 / 重排 / 多模态、状态）；新增模型（选供应商 → BaseURL / API Key → 测试连通 → 保存）；编辑 / 删除；模型调试（发起真实调用，展示返回结果）
  - Web 搜索配置：供应商（Bing / Google / 百度 / Tavily 等）选择、凭据、启用状态
  - 解析引擎：Docling / MinerU 可用状态、支持格式说明（PDF / Word / 图片 / Markdown）、默认映射
  - 聊天历史：会话保留策略（保留天数 / 条数）
- **系统管理组**（管理员）
  - 系统管理：系统级全局设置
  - 运行时任务队列：队列监控仪表盘（各阶段积压量、活跃 worker、失败任务列表可查看错误与重试、完成量统计）
  - 审计日志：操作人 / 动作 / 对象 / 结果 / 时间，筛选与分页
  - 平台 API Keys：创建 / 撤销、作用域说明
  - 版本信息：产品版本、运行环境

**交互与跳转**：
- 侧边导航切换各分节
- 新增模型 → 表单 → 测试连通（成功 / 失败提示）→ 保存
- 模型调试 → 弹窗展示调用结果
- 成员管理中的邀请 / 移除 / 转移所有权均需确认

## 七、角色与权限（设计时注意）

- 仅两种角色：**Owner**（全部权限，含转移所有权）/ **Admin**（除转移所有权外全部管理权限）。
- 知识库：创建者 / 管理员可编辑删除；共享给组织的知识库按共享权限（查看 / 编辑）开放。
- 界面按权限**显隐或禁用**操作（如无权限时不显示删除、设置等入口）。

## 八、通用组件清单（需统一设计）

卡片、表格、抽屉、模态框、弹层菜单、下拉选择、标签、进度条、状态徽章（处理中 / 成功 / 失败）、骨架屏、空状态、确认对话框、Toast 提示、分页 / 加载更多、文件上传（含拖拽）、Markdown 渲染区域、图谱画布。

## 九、设计交付要求

- 覆盖全部页面与交互；每个页面给出默认态 / 空态 / 加载态。
- 关键流程给出交互说明：上传 → 解析中 → 完成 / 失败；新建知识库向导；图谱节点点击联动；对话工具调用过程与引用查看。
- 建议先给 2~3 个差异化方向提案并推荐其一，再完成全量设计。
