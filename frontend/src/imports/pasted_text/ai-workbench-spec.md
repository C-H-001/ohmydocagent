# Figma 设计任务书：AI 原生知识工作台（智能问答 + 知识图谱）

## 〇、设计基调（必读）

- 这是一个**全新产品**，不是任何现有产品的改版。**禁止照搬** WeKnora、Notion、飞书知识库、语雀、TDesign 等现有产品的视觉风格、布局模板或组件形态；但**页面结构、功能跳转关系可以参考本任务书第三章的页面地图**（该地图已按功能逻辑重新组织，非原样照搬）。
- 本任务书规定：**"每个页面有哪些功能、点击哪里跳转到哪"**（第三章，硬性要求）。**"页面怎么布局、长什么样"完全由你设计**（第四章自由域）。
- 产品：桌面浏览器优先的企业级 Web 应用，单工作区、多知识库、组织共享，界面仅中文，信息密度高、状态完整。
- CHATGPT的截图仅供参考
---

## 一、产品定位

AI 原生企业知识工作台，两大核心能力：
1. **智能问答**：RAG + 智能体推理（ReAct 多步工具调用 + Web 搜索 + 深度思考）的对话式知识检索。
2. **知识图谱**：解析时 LLM 自动抽取实体与关系，形成可视化知识网络，支持从图谱反查文档。

文档格式：PDF / Word / 图片 / Markdown（解析引擎：Docling / MinerU）。

---

## 二、角色与权限（影响界面显隐）

- 仅两种角色：**Owner**（全部权限，含转移所有权）、**Admin**（除转移所有权外全部管理权限）。
- 知识库权限：创建者 / 管理员可编辑删除；共享给组织的知识库按共享权限（查看 / 编辑）开放。
- 界面按当前用户权限显隐或禁用操作（无权限时不显示删除、设置等入口）。

### 1. 登录 / 注册 / 初始化
- **登录页**：账号、密码、登录按钮、错误提示；忘记密码提示（联系管理员重置）。
- **初始化**（系统未配置时，首次访问自动进入）：引导创建管理员账号（昵称 / 账号 / 密码），完成后跳转登录。
- **注册页**：管理员邀请链接进入（昵称 / 账号 / 密码 / 确认密码），注册成功直接登录。
- 登录成功 → **知识库列表**。

### 2. 主框架（全局导航，所有业务页共用）
- 导航入口（形态自定，功能必需）：
  - **知识库** → 知识库列表
  - **会话** → 会话列表（聊天）
  - **组织** → 组织列表
  - 用户区：头像 / 昵称 → 下拉（**设置** → 设置中心；**退出登录**）
- 会话列表建议常驻于框架中（见页面 6），但形态不限（侧栏 / 抽屉 / 独立页均可）。
- 全局能力：拖文件入窗口 → 上传到当前知识库或聊天（全屏遮罩 + 进度）；统一 Toast；破坏性操作二次确认。

### 3. 知识库列表
**功能模块：**
- 空间筛选：全部 / 我的 / 收藏 / 最近（带数量）；共享给我的知识库按来源组织分组显示（组织名 + 数量）。
- 知识库卡片：名称、描述、文档数量、**知识图谱启用徽章**、来源（我创建的 / 来自某组织）。
- 卡片操作：收藏星标、更多菜单（置顶 / 取消置顶、复制、设置、删除）。
- 未初始化 / 处理中的知识库：弱化样式 + 提示。
- 顶部主操作：**新建知识库**。

**跳转：**
- 新建知识库 → **新建向导**（模态框，多步骤：① 基本信息 → ② 索引策略[向量搜索默认开 / 知识图谱抽取开关，至少其一] → ③ Embedding / 摘要模型选择 → ④ 分块配置 → ⑤ 解析引擎规则映射）→ 创建成功 → 进入**知识库详情**。
- 点击卡片 → **知识库详情**。
- 更多菜单"设置" → **知识库设置**（页面 9）；"删除" → 确认后移除。

### 4. 知识库详情
**顶部**：面包屑（知识库 > 当前库名）+ Tab：**文档** / **知识图谱**；右侧：信息按钮（弹层：统计概览）、设置按钮、**开始对话**按钮（→ 新建会话并自动 @ 当前知识库）。

#### Tab A：文档管理
**功能模块：**
- 文件夹组织：树形浏览（根目录 + 子文件夹）、新建 / 重命名文件夹、拖拽文档到文件夹移动、路径面包屑。
- 工具栏：关键词搜索；标签筛选（弹出面板：多选 + 计数 + 搜索 + **管理标签**入口）；文件类型筛选（PDF/Word/图片/Markdown）；解析状态筛选（全部/处理中/成功/失败）；来源筛选（上传/URL/手动）；更新时间范围；视图切换（网格 / 列表）；上传入口（下拉：上传文件 / 从 URL 导入 / 手动创建）。
- 文档列表项：名称、文件夹、类型图标、标签、大小、解析状态（处理中进度 / 失败原因可重试）、更新时间。
- 文档操作：预览、重新解析、取消解析、下载、移动到文件夹、编辑标签、删除。
- 多选（勾选 / 框选）→ 底部批量操作栏：批量删除 / 重新解析 / 打标签 / 移动。
- 上传进度面板（顶部）；空状态（引导上传第一个文档）；筛选无结果状态。

**跳转：**
- 点击文档 / "预览" → **文档预览抽屉**（页面 5）。
- "手动创建" → 编辑器（模态框或抽屉）：Markdown 正文 + 元数据 → 保存后进入解析。
- "管理标签" → 标签管理抽屉（增删改标签、查看每个标签的文档数）。
- "设置"按钮 → **知识库设置**（页面 9）；信息按钮 → 统计弹层。

#### Tab B：知识图谱
**功能模块：**
- 可视化画布：节点 = 实体（类型区分样式），边 = 关系（标注名称）；缩放 / 平移 / 拖拽节点。
- 顶部：实体搜索框、实体类型筛选、图例。
- 空状态：提示"启用知识图谱抽取后，新上传文档将自动构建图谱"。

**跳转：**
- 点击节点 → **实体详情面板**（名称、类型、描述、关联文档列表）。
- 实体详情中点击关联文档 → **文档预览抽屉**（页面 5）。

### 5. 文档预览抽屉（右侧抽屉）
**功能模块：**
- 头部：标题、下载按钮、**解析时间线**入口。
- 元数据区：类型、来源、上传 / 更新时间、标签（可编辑）。
- 正文预览：Markdown 渲染 / 图片预览；自动摘要（可重新生成）。
- **解析时间线**（展开面板）：上传 → 解析 → 向量化 → 图谱抽取各阶段状态与耗时。
- **分块列表**：解析出的文本分块（含分块内图片）。

**跳转：**
- 点击分块 → 分块编辑（内联或编辑框，保存后自动重新向量化）。
- 分块编辑内 → **版本历史**（快照列表 → 行级 diff 对比 → 一键回滚）。

### 6. 会话（聊天）
**会话列表（建议常驻框架）：**
- 日期分组（今天 / 昨天 / 更早）；搜索框；会话项操作：置顶、重命名、删除；批量选择删除、一键清空全部；新建会话入口。

**聊天区：**
- **空会话**：居中大输入框（无推荐问题卡片）。
- **输入框控件**：@提及（选择知识库 / 文件）、图片上传、附件上传、模型选择器、Web 搜索开关、发送 / 停止生成。
- **用户消息**：文本、@提及 chip、图片、附件。
- **助手消息**：
  - 流式 Markdown 输出
  - 可折叠**深度思考**
  - **RAG 管线进度**（检索 → 重排 → 合并 → 生成）
  - **工具调用过程树**（思考 / 调用工具 / 工具结果，逐条可折叠）
  - **引用来源**（答案中可点击引文，悬浮显示来源摘要）+ **引用抽屉**（本次回答引用的全部文档与分块）
  - **答案工具条**：复制、加入知识库、请求详情（模型 / token 用量）
- 继续生成 / 停止生成；向上滚动加载历史；滚动到底部按钮；会话标题自动生成；可清空消息。

**跳转：**
- @提及 → 选择器弹层（知识库列表 → 展开其文档选择）。
- 模型选择器 → 模型弹层（切换对话模型）。
- "加入知识库" → 选择目标知识库弹层 → 保存为文档。
- 引用抽屉中点击来源文档 / 分块 → **文档预览抽屉**（页面 5）。
- 从知识库详情"开始对话"进入时，自动携带该知识库上下文。

### 7. 组织管理
**组织列表：** 组织卡片（名称、成员数、共享知识库数）；创建组织；加入组织（邀请链接）；右上角邀请铃铛（待处理邀请，接受 / 拒绝）。
**组织设置（模态框）：**
- 基本信息（名称 / 描述）。
- 成员管理：成员列表、角色（Owner / Admin）、添加成员（邀请链接 / 账号）、移除成员、角色调整。
- 共享概览（只读）：共享给该组织的知识库列表。

**跳转：** 点击组织卡片 → 组织设置；组织列表内点击共享知识库 → 跳转该知识库详情（有权限时）。

### 8. 设置中心
**导航分组（形态自定，条目必需）：**
- **账号**：个人资料（昵称 / 邮箱 / 头像 / 修改密码）。
- **工作区**：工作区信息（名称 / 创建时间 / 存储用量，只读）；成员管理（成员列表、角色 Owner / Admin、邀请成员、移除成员、转移所有权[仅 Owner]）。
- **模型与运行时**：
  - 模型管理：已配置模型列表（供应商 / 模型 / 类型：对话 / Embedding / 摘要 / 重排 / 多模态 / 状态）；**新增模型**（选供应商 → BaseURL / API Key → 测试连通 → 保存）；编辑 / 删除；**模型调试**（发起真实调用，结果弹层）。
  - Web 搜索配置：供应商（Bing / Google / 百度 / Tavily 等）凭据与启用。
  - 解析引擎：Docling / MinerU 可用状态、支持格式说明（PDF / Word / 图片 / Markdown）。
  - 聊天历史：会话保留策略（天数 / 条数）。
- **系统管理**（管理员）：
  - 系统管理：系统级全局设置。
  - 运行时任务队列：队列监控仪表盘（各阶段积压量 / 活跃 worker / 完成量；失败任务列表 → 查看错误 → 重试）。
  - 审计日志：操作人 / 动作 / 对象 / 结果 / 时间，筛选分页。
  - 平台 API Keys：创建（创建后仅展示一次密钥）/ 撤销、作用域说明。
  - 版本信息：产品版本、运行环境。

### 9. 知识库设置（编辑，模态框）
从知识库详情"设置"进入，分节导航：基本信息 → 索引策略 → 分块配置 → 解析引擎规则 → 模型（Embedding / 摘要）→ 检索（召回阈值 / TopK）→ **共享**（选择组织 + 查看 / 编辑权限）→ 危险操作区（删除知识库，二次确认）。

## 四、设计自由域（鼓励差异化）

- **信息架构与导航形态**：不限左侧导航；欢迎顶部导航、工作台 dashboard、双栏 / 三栏、浮动面板等方案；会话列表的常驻位置可自行设计。
- **页面布局**：不限卡片 / 表格 / 列表 / 分栏；每个功能点选择最合适的呈现方式。
- **交互范式**：鼓励 AI 原生（对话式、图谱式、命令式）；可在智能问答 / 知识图谱 / 文档管理间设计融合视图，但保持各功能完整可达。
- **视觉语言**：完全自由，但需自洽（建议输出一套完整设计系统：组件、图标、排版、色彩逻辑）。

## 五、全局规范与交付要求

- 所有列表 / 卡片覆盖三态：加载（骨架屏）、空（引导文案 + 主操作）、有数据。
- 异步任务（上传 / 解析 / 图谱抽取 / 复制知识库 / 模型调试）有进度反馈与失败重试。
- 统一消息提示、分页与加载更多；破坏性操作二次确认。
- 覆盖全部页面，每个页面给出默认态 / 空态 / 加载态；关键流程给出交互说明：① 上传 → 解析中 → 完成 / 失败；② 新建知识库向导；③ 图谱节点点击联动文档；④ 对话工具调用过程与引用联动；⑤ 邀请成员 → 接受邀请。
- 复用型组件统一设计：卡片、表格、抽屉、模态框、弹层菜单、标签、进度条、状态徽章、骨架屏、空状态、确认对话框、Toast。
