OhMyDocAgent 是一个面向个人和团队的 AI 知识工作台。你可以把报告、手册、学习笔记等资料整理进知识库，在对话中选择知识库或具体文件提问，并通过回答中的引用查看相关资料。

不需要先搭建环境，打开 [在线体验](http://ohmydocagent.xyz/) 即可注册、登录。开始问答前，请先配置自己的模型。

## 核心功能

- **整理多种资料**：导入 PDF、Word（.docx）、图片（PNG、JPG、JPEG、WEBP）、Markdown 和 TXT，用知识库、文件夹和标签分类管理。
- **指定范围提问**：通过 `@` 选择一个或多个知识库，也可以指定具体文件，集中查找本次问题需要的资料。
- **查看回答来源**：回答可以附带文档引用，方便打开相关文档和片段核对；图表相关回答还可以展示来源图片。
- **阅读文档与图表**：预览解析结果、分块和文档摘要；图片经视觉模型生成描述后，也能参与资料检索。
- **探索知识关联**：按需开启知识图谱，查看文档中的实体及关系，辅助理解跨文档的关联信息。
- **协作与用量查看**：邀请其他用户访问知识库，在设置中心查看自己的模型配置和已记录的调用、Token 用量。

## 开始使用

### 1. 注册并登录

访问 [OhMyDocAgent](http://ohmydocagent.xyz/)，注册账号后登录。

如果你是来使用他人共享的知识库，请先注册，再让知识库创建者通过你的注册邮箱邀请你。

### 2. 配置模型

进入左侧 **设置中心 → 模型管理**，点击 **新增模型**，按照所用模型服务的要求填写服务地址、模型名称和 API Key（如需），启用模型并设置相应类型的默认模型。

| 模型类型 | 用途 | 使用建议 |
|---|---|---|
| 对话模型 | 理解问题、生成回答和摘要，参与知识图谱抽取 | 开始问答前配置 |
| Embedding（嵌入）模型 | 将文本转换为可供语义检索的表示 | 创建自己的向量知识库前配置 |
| 重排序模型 | 对已找到的候选资料进一步排序 | 按需配置 |

注册账号不会自动配置这些模型。模型调用的额度和费用取决于你接入的服务；模型用量页用于查看统计，实际账单以服务商记录为准。

### 3. 创建知识库

进入 **知识库**，新建一个知识库，填写名称和描述，并选择已配置的嵌入模型。

可以按用途分别建立“项目资料”“产品手册”“学习笔记”等知识库。分块设置可以先使用默认值；需要探索人物、概念或组织之间的关系时，再按需开启知识图谱。

### 4. 导入资料并等待处理

进入知识库后上传文件。系统会在后台进行解析、分块和向量化，摘要及图谱按配置生成。

- 在文档列表和预览中查看处理状态、阶段信息及解析结果。
- 上传成功不等于所有处理阶段都已完成；先确认解析和向量化完成，再检查检索效果。
- 文件较长、扫描页较多或包含大量图表时，请留出处理时间，避免反复上传同一文件。
- 支持的上传大小以上传界面的提示为准。

### 5. 选择资料并提问

在知识库中点击 **开始对话**，或进入会话后在输入框键入 `@`，从候选列表选择知识库或文件，再输入问题。

可以从这些问题开始：

- “概括这份报告的三个核心结论，并标注资料来源。”
- “对比选中的两份产品手册，列出安装步骤上的区别。”
- “这张图展示了什么趋势？请结合原图说明，并指出看不清的数值。”
- “根据已建立的知识图谱，解释这两个概念之间的关系。”

回答生成后，结合引用查看原文。需要更精确的结果时，可以缩小到具体文件，补充对象、时间范围或其他限制，再继续追问。

## 知识库与协作

知识库通过授权方式共享。创建者可以在 **邀请成员** 或 **知识库设置 → 共享管理** 中，按已注册用户的邮箱添加协作者，并按需调整或移除授权。

协作者的操作范围取决于所获得的权限。共享知识库不需要互相提供模型 API Key；使用共享资料进行向量检索时，系统沿用该知识库的向量配置，不会用访问者的默认嵌入模型替换它。

## 使用建议

- **先确认资料完整，再调整提问方式。** 如果答案不在所选文档里，模型不应成为资料的替代品。
- **给问题限定范围。** 指定文件、时间段、对象和期望的输出形式，比笼统地问“介绍一下”更容易得到有用结果。
- **核对图表中的关键数字。** 扫描清晰度、复杂表格和图片识别都可能影响结果，重要数字、单位和结论请对照原文。
- **按需开启知识图谱。** 图谱适合探索关联，不是每份资料都需要；抽取会增加处理时间和模型调用。
- **妥善保管凭据和资料。** 建议使用专用、受限额的 API Key，并确认你所接入的模型服务如何处理上传内容。

## 常见问题

### 为什么注册后还不能开始问答？

账号和模型配置是两回事。请先在 **设置中心 → 模型管理** 中配置并启用自己的对话模型；创建向量知识库还需要可用的 Embedding 模型。出现连接错误时，检查服务地址、模型名称、API Key 和服务额度。

### 为什么上传后暂时搜不到内容？

文件可能仍在排队或处理中，向量化也可能尚未完成。先查看文档的处理阶段和解析结果；如果显示失败，按照错误提示检查配置，再重试对应操作。也可以先选一份已完成处理的短文档验证流程。

### 为什么回答不准确，或者没有引用？

先确认已通过 `@` 选中合适的资料，并检查解析结果是否包含所需信息。回答和引用也受所用模型的能力影响；没有可靠来源时，请回到原文确认，不要把生成内容当作已核实的事实。

### 可以给不同知识库使用不同的嵌入模型吗？

可以，在创建知识库时选择即可。已有知识库需要更换嵌入模型或维度时，由创建者进入 **知识库设置 → 向量配置 → 重建向量**，选择模型并开始重建，完成后点击 **应用重建结果**。

仅修改用户默认模型，不会自动改变已有知识库的向量配置。重建会调用模型，请根据资料规模预留处理时间和额度。

### 为什么看不到别人创建的知识库，或找不到管理入口？

请确认创建者已经通过你的注册邮箱共享了知识库。部分操作只对创建者或具备相应权限的用户开放，例如向量重建由创建者操作。
